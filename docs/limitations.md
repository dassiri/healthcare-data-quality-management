# Limitations

- The datasets are fully synthetic and illustrative.
- This is a portfolio project, not a production system.
- No real healthcare data is used or stored.
- No organisational implementation is claimed.
- No regulatory, NDMO, NPHIES, or clinical-safety compliance is claimed.
- Issue statuses are a workflow simulation, not a live service-management integration.
- Power BI CSV/Excel extracts are provided; a `.pbix` dashboard file is not included.
- Remediation does not invent missing clinical dates; residual validity failures are intentional.
